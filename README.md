# MediFamba

MediFamba é uma plataforma de agendamento e gestão de consultas médicas desenvolvida para otimizar o atendimento em estabelecimentos de saúde. O sistema simplifica a marcação de consultas, o acompanhamento de horários e a organização dos dados de pacientes e profissionais de saúde.

---

## Funcionalidades Principais

* **Gestão de Agendamentos:** Marcação, reagendamento e cancelamento de consultas médicas.
* **Cadastro de Pacientes e Médicos:** Registo detalhado de perfis para facilitar o histórico clínico.
* **Painel de Controlo:** Visualização das consultas agendadas para profissionais e administradores.
* **Autenticação e Autorização:** Controlo de acesso baseado em perfis (Paciente, Médico, Administrador).

---

## Tecnologias Utilizadas

* **Backend:** Java (Spring Boot)
* **Base de Dados:** PostgreSQL
* **Migrações de Base de Dados:** Flyway
* **Contentorização:** Docker
